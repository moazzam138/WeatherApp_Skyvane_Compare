# 🌤 Skyvane Compare

Skyvane Compare is a modern real-time weather comparison web application built using React, Vite, and Tailwind CSS. The application allows users to compare weather conditions of two cities simultaneously with a clean responsive dashboard UI.

---

# 🚀 Features

- 🌍 Compare weather of two cities side by side
- 🌡 Real-time temperature updates
- 💧 Humidity, pressure, visibility & wind details
- 📅 5-Day weather forecast
- ⏰ Hourly weather forecast
- 🎨 Dynamic weather-based backgrounds
- 🔄 Celsius / Fahrenheit conversion
- 📱 Fully responsive UI
- ⚡ Fast API integration using OpenWeatherMap
- 🧩 Reusable React component architecture
- 🌫 Glassmorphism UI design
- ❌ Error handling & loading states

---

# 🛠 Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- OpenWeatherMap API
